# ChorusYarn

ChorusYarn is a High-Performance, auto-scaling data processing Platform Engine, built on robust load balancing principles.

ChorusYarn is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/ChorusYarn.git`
2. `cd ChorusYarn`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure ChorusYarn, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
